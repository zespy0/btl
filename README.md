# 빈틈랩 웹앱 프로토타입

React + TypeScript + Vite 기반 한국어 데모. Node.js 20.19 이상에서 실행합니다.

```powershell
cd "C:\Users\user\Desktop\부산 지역문제\binteum-app"
npm.cmd install
npm.cmd run dev
```

표시되는 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm.cmd run build`로 dist에 생성합니다.

## 디자인 시스템

레트로 코믹 / 아케이드 포스터 톤입니다. 다크 잉크 배경(`#101018`) 위에 Anton 대문자 헤드라인과 하드 오프셋 그림자를 얹고, 카드와 버튼은 굵은 외곽선과 6px 오프셋 그림자로 스티커처럼 처리합니다. 색상 토큰은 오렌지 `#FF7A2F`, 핑크 `#FF4FA3`, 옐로 `#FFD23F`, 민트 `#35C9A9`, 스카이 `#5BB8FF`이며 크림 `#FDF6E9` 배경과 대비를 만듭니다. 토큰과 컴포넌트 스타일은 `src/theme.css`에 모여 있습니다.

마스코트 "틈이"는 빈 공간(집)에 눈이 달린 형태의 SVG 캐릭터로, `src/mascot.tsx`에서 색상 4종과 표정 4종(happy / think / wow / wink)을 조합해 사용합니다. 같은 파일에 역할 아이콘 3종과 조건 픽토그램 5종(안전·권리·접근·비용·주민협의)이 함께 들어 있습니다. 모든 애셋은 인라인 SVG라 외부 이미지 요청이 없고 화면 크기에 관계없이 선명합니다.

후보지 카드의 마스코트 색은 데이터 성격을 따릅니다. 가상 시연 데이터는 민트, 권리·안전 미확인은 오렌지에 `think` 표정, 나머지는 스카이입니다. 상단 티커(`src/ticker.tsx`)는 사실 경계 문구를 반복 노출합니다. `prefers-reduced-motion`을 켠 환경에서는 마스코트와 티커 애니메이션이 멈춥니다.

## 역할별 시연 흐름

### 팝업 운영자

1. 시작하기 → 지도에서 후보지 보기
2. 지도 핀 또는 카드에서 후보지 선택 (검색·동네·데이터 구분·확인된 곳만 필터)
3. 상세에서 조망 측정 슬라이더(방위·화각·층수)와 다섯 조건 확인
4. 공간 모델링에서 배치안 생성 (내장 시연 모드 또는 Gemini 연동 모드)
5. 준비 순서에서 확인 순서 초안 생성·체크·저장·인쇄

### 앱 관리자

후보지 대장에서 조건 집계와 운영 판단을 확인하고, 공개 상태 탭에서 방문자 공개 여부를 제어합니다. 권리 또는 안전이 미확인인 후보지는 공개 토글이 비활성화됩니다. 문의 처리 탭에서 접수 → 담당 배정 → 회신 완료 상태를 순환시킵니다.

### 방문자

공개된 팝업의 운영 시간, 가는 길, 경사, 주차와 방문 전 확인 사항을 봅니다. 관심 표시는 이름·연락처 없이 집계만 합니다.

## Gemini 연동

공간 모델링 화면에서 연동 모드를 선택하고 Google AI Studio 키를 입력하면 `gemini-2.5-flash-image` 모델을 직접 호출합니다. 키는 브라우저 `sessionStorage`에만 보관하며 탭을 닫으면 사라집니다. 서버로 전송하거나 저장소에 기록하지 않습니다. 키가 없거나 호출이 실패하면 내장 계산 결과로 대체하고 실패 사유를 표시합니다. 모델이 이미지를 반환하면 생성 이미지임을 명시해 함께 보여줍니다.

## 데이터 구분과 사실 경계

후보지는 세 가지로 구분해 표시합니다.

- 현장 실증 기록: 청학동 88-9 일대. 제공된 3차 실증 기록의 경사·계단·주차·야간 조도 관찰에 근거합니다. 55.48㎡는 보고서가 인용한 공공데이터 요약 표기이며 공터 실측이 아닙니다.
- 팀 입력 샘플: 청학동 391-576, 동삼동, 남항동. 조건 대부분이 미확인인 검토 대상입니다.
- 가상 시연 데이터: `[시연]` 접두사가 붙은 봉산마을·영선동 공간. MVP 시연을 위해 조건이 충족된 상태를 가정한 값이며 실재 매물이 아닙니다.

추가로 지켜지는 경계는 다음과 같습니다.

- 지도는 영도 형태를 본뜬 개략도입니다. 좌표·거리·축척이 실제와 다르며 위치 서비스가 아닙니다.
- 조망 측정은 개략도 기준 추정입니다. 기준값을 바꾸면 사용자가 조정한 값임을 표시합니다.
- 배치안과 수용 인원은 면적 가정에 따른 계산이며 도면·구조·소방 검토를 대신하지 않습니다.
- 소유자 개인정보와 연락처를 노출하지 않으며, 앱 사용자에게도 개인정보를 받지 않습니다.
- 주차장·셔틀 제휴, 구청 데이터 연계, 소유자 일괄 동의는 구현하지 않았습니다.
- 준비 순서 체크는 문의 준비 표시이며 적합 판정이 아닙니다. 체크리스트만 `localStorage`에 저장하고 초기화 버튼을 제공합니다.
